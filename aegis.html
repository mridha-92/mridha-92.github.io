Overview

Cyber_pent Motor Cortex combines the full offensive security workflow with asset-level defensive visibility. From vulnerability discovery to automated remediation and endpoint telemetry, every layer speaks to the same mission-control dashboard — built for SOC analysts, red teams and executives alike.

CSAM

Discovers, normalizes and tracks 52+ IT assets across servers, cloud instances, IoT devices and endpoints with 4 sensor types.

VAPT Pipeline

End-to-end penetration testing workflow with finding documentation, evidence attachment and PDF report generation.

Vuln Management

39 tracked vulnerabilities with severity/CVSS scoring, CVE correlation and remediation tracking across 16 domains.

Threat Intelligence

8 external feeds — NVD, CISA KEV, MITRE ATT&CK, AlienVault OTX, Abuse.ch, PhishTank, Shodan and OWASP.

Adversary Simulation

Red-team engine with MITRE ATT&CK mapping, 7-phase kill-chain campaigns and purple-team collaboration.

Real-time Alerting

Live security alert feed with IP blocklisting and severity-based routing for instant response.

AI Copilot

Google Gemini-powered natural-language security analysis, remediation scripts and report generation.

TruRisk Engine

Proprietary context-aware risk scoring: CVSS × RTI multipliers × Asset Criticality.

Rust EDR Agent

Endpoint agent with 25+ collectors, AES-256-GCM encryption and mTLS C2 communication.

Architecture

Seven Dockerized services share the internal aegis-net bridge. Nginx reverse-proxies the SPA and routes /api/* to the API server; the C2 server handles agent traffic over mutual TLS.

04

Platform Security

Defense in Depth

Four-layer model: application (JWT, bcrypt, Zod, Helmet), network (mTLS, internal bridge), data (AES-256-GCM, Argon2, parameterized SQL) and infrastructure (non-root containers, health checks).

Agent & C2

Mutual TLS prevents MITM and unauthorized registration; certificate pinning, AES-256-GCM at rest, rules of engagement and data taint tracking for simulation accuracy.

RBAC

6 roles across 5 clearance levels with 22 granular permissions — 132 role-permission combinations in 7 categories, plus full audit trail on every action.

Compliance

Mapped to NIST and ISO 27001 across access control, audit logging, encryption, vulnerability management, incident response and configuration management.

### Executive Summary
A developer operating under the handle /u/TheDevProject has announced a beta testing phase for "Resku," a free anti-phishing browser extension available for Chrome, Edge, Brave, and Arc. The tool is designed to identify fraudulent web pages—such as fake postal notifications, tax scams, and cloned banking portals—including newly registered malicious domains active for less than 24 hours.

The developer is currently soliciting French-speaking users to conduct real-world beta testing to evaluate the extension's performance, false positive and negative rates, alert clarity, and privacy controls. The extension requires no user registration, credit card details, or account creation.

### Technical Impact & Root Cause
Resku operates by evaluating web pages and generating a safety score from 0 to 100 before a user inputs sensitive information, such as passwords, IBANs, or payment card details. The core engine conducts local Document Object Model (DOM) analysis entirely within the browser, ensuring page content remains local while transmitting only the URL, domain, and technical telemetry to an external API for score refinement.

The detection mechanism incorporates over 120 rules, approximately 190 distinct verification checks, and monitoring for more than 150 protected brands. The extension specifically checks for typosquatting variations (such as replacing lowercase "l" with uppercase "I"), as well as in-page malicious scripts, including keyloggers, obfuscated JavaScript, and unauthorized data exfiltration mechanisms.

### Mitigation & IOCs
Recommended defense measures based on the source include implementing proactive browser-level DOM analysis, identifying typosquatted domain variations, and screening web pages for embedded keyloggers or obfuscated code prior to user credential submission.

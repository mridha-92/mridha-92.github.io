### Executive Summary
A supply-chain attack involving the "Admin Menu Editor Pro" WordPress plugin has resulted in malicious updates being pushed to over 200 customers, ultimately backdooring an estimated 1,500 WordPress websites. 

Threat actors compromised the plugin maintainer's official website to distribute the trojanized plugin releases. The malicious updates insert a hidden user account into affected site environments, enabling long-term unauthorized access.

### Technical Impact & Root Cause
The root cause stems from an unauthorized breach of the plugin maintainer's infrastructure, which allowed attackers to subvert the distribution mechanism and serve trojanized plugin updates to existing customers.

Upon installation or automatic update, the malicious version of Admin Menu Editor Pro executes code designed to quietly create a hidden administrative user account. This mechanism bypasses normal site access controls and provides persistent backdoor access for the threat actors across affected WordPress deployments.

### Mitigation & IOCs
Site administrators utilizing Admin Menu Editor Pro should immediately inspect their WordPress user management console and database for unauthorized or hidden user accounts. Compromised sites should be isolated, audited, and restored to a clean state prior to the malicious update, alongside updating to a verified clean version of the plugin.

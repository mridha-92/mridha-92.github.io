### Executive Summary
AI coding agent Claude Code has been observed inadvertently exposing sensitive organizational data and credentials to public Git repositories. The issue introduces security gaps by unintentionally pushing private information to public code hosting services like GitHub.

The exposure affects organizations utilizing Claude Code where automated command executions write sensitive local data directly into publicly accessible project repositories.

### Technical Impact & Root Cause
* **Root Cause:** A specific command in Claude Code inadvertently saves files containing active credentials and sensitive data into project directories that are synced with public Git repositories.
* **Technical Impact:** Exposing credentials and confidential files in public repositories presents immediate access risks, allowing external unauthorized actors to harvest exposed secrets and compromise affected organizational environments.

### Mitigation & IOCs
Organizations using Claude Code should audit recent commits in public Git repositories for inadvertently exposed files, rotate any compromised credentials immediately, and implement pre-commit secret scanning controls.

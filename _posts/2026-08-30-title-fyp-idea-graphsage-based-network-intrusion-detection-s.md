### Executive Summary

An academic research inquiry published on Reddit CyberSec details a proposed Final Year Project (FYP) focused on developing a Network Intrusion Detection System (NIDS) using Graph Neural Networks (GNNs). The project aims to utilize the GraphSAGE architecture to monitor network traffic, classify flows as benign or malicious, identify specific attack types, and trigger automated alerting or preventive mechanisms.

The primary objective of the prototype is to evaluate deep learning graph models for automated threat detection and potential prevention. Initial training and benchmarking are planned around the public CIC-IDS2017 dataset, with additional evaluation datasets under consideration to measure real-time classification performance.

### Technical Impact & Root Cause

The proposed technical implementation focuses on representing network infrastructure as a graph structure, assigning hosts and IP addresses as nodes while defining network flows as connecting edges. Model features under evaluation for edge and node attribution include network protocols, source and destination ports, packet and byte counts, flow durations, TCP flags, packet inter-arrival times, and connection statistics.

Key technical challenges raised in the proposal center on optimizing graph construction and model selection for intrusion detection. The research explores whether GraphSAGE is optimal compared to alternative architectures—such as Graph Convolutional Networks (GCN), Graph Attention Networks (GAT), or temporal GNNs—and highlights the need to benchmark GNN results against traditional machine learning baselines like Random Forest and XGBoost.

### Executive Summary
Threat actors compromised Coder's Cloudflare infrastructure to manipulate software distribution channels.

The unauthorized access enabled attackers to add rogue registry servers that delivered malicious Terraform modules containing credential-stealing code to impacted users.

### Technical Impact & Root Cause
The root cause of the incident was an intrusion into Coder's Cloudflare infrastructure, which allowed adversaries to alter network and routing configurations.

As a direct technical impact, the unauthorized registry servers served malicious Terraform modules designed to harvest credentials from environments fetching components from the compromised infrastructure.

### Mitigation & IOCs
Specific remediation actions were not detailed in the source material. Security teams using Coder infrastructure should audit Terraform module sources, inspect deployment pipelines for unexpected registry connections, and rotate sensitive credentials as a precautionary measure.

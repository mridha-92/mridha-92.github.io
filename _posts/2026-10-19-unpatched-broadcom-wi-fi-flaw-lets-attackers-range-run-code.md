### Executive Summary

An unpatched security vulnerability in Broadcom's Wi-Fi setup software allows attackers within radio range to execute arbitrary code with root privileges on affected routers. Disclosed by security researcher Quentin Kaiser on October 16, the flaw requires no prior network password, authentication, or pairing procedure.

The researcher demonstrated the attack against home gateways supplied by three internet service providers in Belgium. During the demonstration, the exploit enabled the researcher to remotely read the plain-text Wi-Fi password directly off the target gateway device.

### Technical Impact & Root Cause

The flaw originates in Broadcom's Wi-Fi setup software deployed across various router models. Because the weakness exists in the setup mechanism, an unauthenticated attacker only needs to be within physical Wi-Fi signal range of the device to deliver the payload over the air.

Successful exploitation grants the attacker full root access to the underlying router operating system. This level of compromise allows malicious actors to manipulate gateway settings, inspect or intercept network traffic, and retrieve sensitive configuration data, including stored Wi-Fi credentials.

### Mitigation & IOCs

Specific vendor patches or official workarounds from Broadcom or the affected Belgian internet service providers are not yet confirmed. Users and network administrators should monitor ISP advisories for upcoming firmware updates addressing Broadcom's setup software.

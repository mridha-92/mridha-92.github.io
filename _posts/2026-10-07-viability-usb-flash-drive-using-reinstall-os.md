### Executive Summary
A community inquiry published on Reddit's r/cybersecurity forum by user `/u/Fantastic-Affect-883` raises questions regarding the security integrity of a USB flash drive after using it to reinstall an operating system on a compromised computer. 

The user created OS installation media on a clean, uncompromised device and booted directly from the BIOS to perform a complete Windows reinstallation on an infected machine. The inquiry seeks clarification on whether connecting a USB drive to a compromised host during a clean reinstallation renders the drive unsafe for future use.

### Technical Impact & Root Cause
The core technical concern centers on whether malware from a compromised host can infect a bootable USB drive during the OS reinstallation process. In the reported scenario, the primary infected Windows OS was not booted while the USB drive was attached, as the machine was booted directly into the installation environment via BIOS.

Because the source consists of a user support question, specific details regarding the malware family, technical mechanisms of potential cross-contamination, or system impact are not provided in the source material.

### Mitigation & IOCs
General mitigations discussed in the context of handling media exposed to compromised hardware include re-partitioning and reformatting the USB drive on a known-secure system, or retiring the media if advanced firmware-level persistence is suspected.

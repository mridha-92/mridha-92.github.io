### Executive Summary
A security flaw named "WPSplinter" has been identified in Broadcom's legacy Wi-Fi Protected Setup (WPS) Monitor implementation. The issue allows an unauthenticated, nearby adversary to reach the underlying EAP-WPS parser directly over a wireless connection.

Exploitation does not require the attacker to know the target network key or successfully complete WPS enrollment. This exposes vulnerable Broadcom-based wireless devices to unauthorized over-the-air processing of malicious packets.

### Technical Impact & Root Cause
The root cause lies in how Broadcom's legacy WPS Monitor handles fragment reassembly. Specifically, the implementation fails to correctly constrain reassembled EAP-WPS fragments to the allocated destination buffer size, resulting in a buffer boundary constraint failure.

Because the vulnerable parser evaluates frames prior to network authentication or session establishment, an attacker within physical Wi-Fi range can transmit specially crafted EAP-WPS fragments to induce memory corruption on the targeted device.

### Mitigation & IOCs
Specific vendor mitigations or patch instructions were not provided in the reported source. Disabling legacy WPS features or updating affected wireless device firmware to non-vulnerable versions is recommended where applicable.

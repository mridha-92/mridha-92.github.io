### Executive Summary
A data exposure incident involving a Vietnam-linked Advance Passenger Information System (APIS) database exposed approximately 220 million passenger and crew records. Security researchers discovered and accessed the system via a cloud-based entry point.

The exposed dataset spans flight and personal details from 2017 to 2026. Compromised information includes full names, passport numbers, dates of birth, nationalities, and specific flight details for affected passengers and aircrew.

### Technical Impact & Root Cause
The exposure was caused by an insecure authentication configuration on a cloud-based path leading to the APIS database. The system was accessible using default credentials, allowing unauthorized external access without requiring sophisticated exploitation techniques.

The technical impact involves a massive loss of confidentiality for sensitive travel metadata and personally identifiable information (PII). Exposed passport numbers and flight histories create significant downstream identity theft and tracking risks for affected individuals.

### Mitigation & IOCs
Organizations maintaining cloud-hosted database systems should immediately review and enforce baseline access controls:
* Audit all cloud endpoints and database deployments to eliminate default administrative credentials.
* Restrict cloud accessibility using strict network access controls, multi-factor authentication, and centralized identity management.

### Executive Summary

SolarWinds has released security updates to patch a high-severity vulnerability in Access Rights Manager (ARM). Tracked as CVE-2026-28326, the vulnerability carries a CVSS severity rating of 8.8 out of 10.0. 

Successful exploitation of the flaw allows an unauthenticated attacker to achieve remote code execution on affected systems. The issue impacts all installations running SolarWinds Access Rights Manager version 2026.2 and earlier.

### Technical Impact & Root Cause

The vulnerability originates from a hard-coded key flaw present within SolarWinds Access Rights Manager. 

An unauthenticated network attacker can leverage this hard-coded key issue to execute arbitrary code remotely on the target host. Because exploitation does not require valid user credentials or authentication, systems exposed to unauthorized network access face severe compromise risks.

### Mitigation & IOCs

Organizations utilizing SolarWinds Access Rights Manager should immediately update their software to a version newer than 2026.2 to resolve the vulnerability. Restrict administrative interfaces and ensure ARM instances are not exposed directly to untrusted networks.

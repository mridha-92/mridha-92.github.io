### Executive Summary
Cyberpent threat intelligence has observed an active malware distribution campaign leveraging GitHub to deliver the SmartLoader payload. The threat actor operates under the GitHub profile `tenrececaudatusarmour182`, which has remained undetected on the platform for approximately three months. 

The campaign utilizes a repository named "MicVST," which masquerades as a legitimate open-source software project. The primary objective of the deployed payload is information theft, specifically targeting passwords and sensitive documents on infected systems.

### Technical Impact & Root Cause
The attack initiates when a user follows the "How to Install" instructions within the repository's ReadMe file, which directs them to download a malicious `.zip` archive. This archive contains an infection chain relying on `Launcher.bat`, an executable file (`*.exe`), and a text file (`*.txt`). 

Upon execution, `Launcher.bat` launches the executable—which functions as a Lua Virtual Machine (VM)—and directs it to process the accompanying `.txt` file. The text file contains obfuscated Lua code that is piped directly into the Lua VM for execution. Once running, the SmartLoader payload resolves a secondary GitHub page that acts as a remote configuration file to issue further instructions to the malware. Successful execution results in the exfiltration of user passwords and sensitive documents.

### Mitigation & IOCs
Organizations and developers should restrict access to the identified malicious GitHub profile and review endpoint activity for unauthorized batch execution of Lua interpreters. Avoid downloading or executing installation archives linked within unverified repository ReadMe files.

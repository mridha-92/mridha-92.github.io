### Executive Summary
Cybersecurity researchers have identified a malicious npm package named `imgdecode`, which is linked to a broader software supply chain attack campaign dubbed MALFEX. The package was published to the official npm registry on September 30, 2026, by a user operating under the handle `malfexteste8`.

Before public disclosure, `imgdecode` accumulated 979 downloads and remained available on the registry. The campaign highlights ongoing supply chain risks targeting Node.js software ecosystems and developer environments.

### Technical Impact & Root Cause
The root cause stems from supply chain compromise via rogue package publication on the public npm registry. Threat actors behind the MALFEX campaign disguised the payload as a legitimate image-decoding library to trick developers into integrating it into their projects.

Technically, the `imgdecode` package conceals a shellcode loader embedded within a Windows native addon. When installed or executed in a targeted Windows environment, the native addon can load and execute arbitrary shellcode, potentially granting attackers remote code execution on developer workstations or build pipelines.

### Mitigation & IOCs
Organizations and development teams should audit their project dependencies immediately to check for `imgdecode`. If identified, remove the package from `package.json` and lockfiles, revoke any exposed credentials or tokens from systems where the package was installed, and inspect build endpoints for unauthorized native process executions.

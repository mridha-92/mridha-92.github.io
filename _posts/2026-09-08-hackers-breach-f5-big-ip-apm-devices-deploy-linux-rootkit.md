### Executive Summary
Threat actors are breaching F5 BIG-IP Access Policy Manager (APM) environments to deploy a specialized Linux rootkit. The campaign aims to establish persistent, highly evasive access on targeted network appliances.

By leveraging fileless execution techniques, attackers can maintain a foothold within affected infrastructure while minimizing the likelihood of detection by security controls.

### Technical Impact & Root Cause
The deployed Linux rootkit operates by intercepting the loading of PHP files on the underlying operating system of F5 BIG-IP APM devices. 

Once intercepted, the malware injects a fileless web shell directly into memory. This mechanism allows the web shell to execute malicious commands without writing code to the disk, bypassing traditional file-based detection mechanisms and disk integrity checks.

### Mitigation & IOCs
Concrete vendor mitigations were not detailed in the source report. Security teams managing F5 BIG-IP APM appliances should audit active processes, inspect memory spaces for unauthorized PHP manipulations, and review system access logs for anomalous behavior.

### Executive Summary
A critical authentication flaw rated CVSS 10.0 has been identified in Canonical's LXD and MicroCloud software. The vulnerability allows unauthorized threat actors to bypass standard cryptographic authentication controls and impersonate legitimate clients.

To execute the attack, a threat actor must have network reachability to the target's HTTPS API and possess a trusted client's public certificate. Exploitation does not require the attacker to hold or steal the client's private key.

### Technical Impact & Root Cause
The root cause stems from a flaw in how the LXD and MicroCloud HTTPS API validates client authentication requests. The service grants access based on the trusted client's public certificate without properly requiring or validating the corresponding private key during the handshake.

If exploited, the threat actor operates with the full permissions assigned to the impersonated client account. This exposes the underlying infrastructure cluster and all hosted virtual machines to unauthorized access and potential control.

### Mitigation & IOCs
Specific software updates or official patches are not detailed in the provided source material. System administrators using LXD or MicroCloud should restrict network exposure to the HTTPS API using firewalls or access control lists until vendor patches are applied.

### Executive Summary
E-commerce platform BigCommerce has alerted multiple merchants to security incidents resulting in data breaches across affected online stores. 

The security alerts follow an investigation revealing that threat actors compromised credentials associated with third-party applications developed by Ribon. Using this unauthorized access, attackers successfully injected malicious scripts into merchants' storefronts.

### Technical Impact & Root Cause
The root cause of the incident involves the compromise of credentials tied to third-party Ribon applications integrated with the BigCommerce platform. 

The technical impact includes unauthorized script injection into compromised merchant websites. Attackers leveraged the elevated access of the Ribon apps to execute arbitrary script code on client-facing e-commerce storefronts. Further details regarding the exact functionality of the injected scripts or the full extent of impacted data remain not yet confirmed.

### Mitigation & IOCs
Merchants operating BigCommerce stores integrated with Ribon applications should audit third-party application permissions, rotate relevant API keys and credentials, and inspect site source code for unauthorized script modifications.

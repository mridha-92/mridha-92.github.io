### Executive Summary

Cloud application hosting platform Northflank has issued a security warning to its customers following a security breach. The incident led to the unauthorized access and subsequent abuse of customers' AI API keys hosted on the service.

Northflank is advising impacted users to take immediate remediative action by rotating all credentials, secrets, and environment variables configured on the platform to prevent further unauthorized usage.

### Technical Impact & Root Cause

The security breach directly impacted the security of stored platform secrets, allowing threat actors to compromise and exploit stored third-party AI API keys. This unauthorized access enables attackers to execute requests using customer accounts, potentially incurring significant financial costs and exposing downstream integrations.

The specific root cause, vector of initial access, and full technical scope of the compromise have not yet been confirmed in the provided release. Investigations into the extent of the platform compromise remain ongoing.

### Mitigation & IOCs

Northflank recommends that impacted customers execute the following mitigation steps:
* Immediately rotate all API keys, access tokens, database credentials, and secrets stored within the Northflank platform environment.
* Audit third-party integration logs—specifically AI service provider dashboards—for abnormal utilization patterns, unauthorized requests, or unexpected cost spikes.
* Revoke compromised API keys at the provider level before issuing fresh credentials.

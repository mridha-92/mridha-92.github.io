### Executive Summary

AI startup MobiusEngine.ai reported a credential compromise on October 7 resulting in the depletion of approximately $35,000 in Google Cloud Platform (GCP) promotional credits within hours. Four legacy, previously near-idle Gemini API keys were leveraged to generate massive unauthorized traffic, impacting the company's operating runway.

The unauthorized activity initiated at approximately 7:00 AM Pacific time and generated roughly 1.17 million requests through 4:06 PM Pacific. The threat actor focused heavily on resource-intensive image generation using the Gemini 3 Pro Image model. Traffic dropped to near zero shortly after the victim identified and deleted the four affected keys at 4:18 PM Pacific.

The incident highlights significant operational risks associated with unmonitored legacy API keys, missing spend controls, and GCP billing visibility delays. The final financial impact and credit restoration status are not yet confirmed due to a multi-hour lag in GCP billing exports.

### Technical Impact & Root Cause

The compromised credentials consisted of four older Gemini API keys stored as plain-text environment variables on legacy Cloud Run services. Additional exposed copies were identified in local development logs and AI coding-tool transcripts after tools inspected service configurations. Scanning of repository histories found no key matches, and the exact vector of exfiltration remains not yet confirmed.

The threat actor engaged in automated key rotation, splitting approximately 1.17 million requests almost equally across the four compromised keys. The workload focused primarily on image generation via Gemini 3 Pro Image, which differed significantly from legitimate company usage. The organization's separate production key maintained standard traffic patterns throughout the incident.

Incident response was impacted by security control gaps and cloud billing latency. The compromised keys possessed API restrictions but lacked application restrictions, budget alerts, or spend limits. Furthermore, GCP billing exports exhibited a delay of over seven hours, while promotional credit offsets masked real-time cost accumulation by showing a net cost of $0 in initial billing views.

### Mitigation & IOCs

To contain the incident, the organization executed the following actions:
* Revoked and deleted all four compromised API keys, stopping unauthorized requests within minutes.
* Initiated a comprehensive security audit of all remaining GCP credentials, secret storage mechanisms, and access controls.
* Engaged GCP support and account representatives to conduct a forensic investigation, establish spend limits, and request restoration of the promotional credits.

Recommended mitigations for cloud API management include enforcing strict application restrictions on API keys, storing secrets in dedicated secret managers rather than plain-text environment variables, and establishing aggressive budget alerts and hard spending caps.

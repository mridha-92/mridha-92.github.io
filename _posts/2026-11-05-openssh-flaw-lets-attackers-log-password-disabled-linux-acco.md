### Executive Summary
A newly disclosed OpenSSH vulnerability, dubbed "*sshole", allows attackers to log into specific Linux accounts that are configured to block password authentication. 

The flaw enables unauthorized access simply by supplying an oversized password during the login process. The issue primarily impacts Alpine Linux and other Linux distributions built on the musl C library.

### Technical Impact & Root Cause
The vulnerability stems from OpenSSH's processing of oversized passwords on systems utilizing the musl C library, such as Alpine Linux. 

Despite accounts being explicitly configured to deny password-based authentication, entering an oversized password string bypasses the restriction, successfully logging the attacker into the password-disabled account.

### Mitigation & IOCs
Specific vendor mitigation steps and official patches were not detailed in the provided source material. Administrators managing Alpine Linux or other musl-based Linux environments should review distribution advisories and update OpenSSH packages once updates are available.

### Executive Summary
A malicious version of Anthropic's Claude Code VS Code extension was distributed through Cursor's extension marketplace on October 29. The fake extension remained active on the platform for approximately 11 hours before removal.

The supply chain incident exposed up to 5,000 developers to malware specifically designed to establish persistent remote access on compromised systems.

### Technical Impact & Root Cause
The root cause involved the distribution of a rogue extension masquerading as Anthropic's official Claude Code tool within Cursor's marketplace. 

The primary technical impact is the execution of malware that attempts to plant persistent SSH backdoors on targeted developer environments, potentially granting threat actors unauthorized access to sensitive local resources and repositories.

### Mitigation & IOCs
Developers who installed or updated the Claude Code extension via the Cursor marketplace on October 29 should immediately uninstall the extension, audit system SSH configurations (including `authorized_keys` files) for unauthorized entries, and rotate any potentially exposed credentials.

### Executive Summary
A security vulnerability involving a hard-coded JSON Web Token (JWT) key has been identified in Issabel PBX. Tracked as CVE-2026-89026, the issue allows unauthenticated or unauthorized attackers to forge administrator authentication tokens.

Exploitation of this vulnerability grants unauthorized access to administrative functions within the PBX software. The vulnerability has been resolved by Issabel PBX maintainers through a software update.

### Technical Impact & Root Cause
* **Root Cause:** The underlying issue was caused by the presence of a static, hard-coded JWT secret key embedded directly within the application code.
* **Technical Impact:** Threat actors aware of the hard-coded key can locally generate valid administrative JWTs. Using these forged tokens, attackers can bypass authentication controls and execute privileged operations across affected PBX system functions.

### Mitigation & IOCs
To mitigate CVE-2026-89026, administrators should update Issabel PBX to the patched release. The patch fixes the issue by relocating the JWT secret key out of the application code and into the system configuration.

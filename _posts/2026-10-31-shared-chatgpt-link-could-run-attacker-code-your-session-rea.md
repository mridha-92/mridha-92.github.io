### Executive Summary
Security researchers at Parameter disclosed a critical vulnerability involving OpenAI's ChatGPT shared link feature. The flaw allowed an attacker to execute malicious code within the active session of any logged-in user who opened a specially crafted link, granting access to the victim's private chat history.

Parameter submitted the vulnerability through OpenAI's bug bounty program on October 18. OpenAI deployed a fix eight days after receiving the disclosure and classified the security issue as P1, its most serious severity rating.

### Technical Impact & Root Cause
* **Technical Impact**: Successful exploitation allowed unauthorized code execution within an victim's authenticated ChatGPT session. This enabled attackers to read private user conversations and compromise session data confidentiality.
* **Root Cause**: The defect stemmed from improper handling or validation of shared ChatGPT links, allowing malicious code to run in the context of the logged-in session of any user who opened the shared URL.

### Mitigation & IOCs
* **Mitigation**: OpenAI addressed and resolved the issue server-side within eight days of the initial report on October 18. Users do not need to take direct remediation actions, though caution should be maintained when opening shared links from untrusted sources.

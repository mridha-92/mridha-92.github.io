### Executive Summary
Cisco has open-sourced Project Quarry, a security rule language created to detect complex AI agent attacks. The tool focuses on identifying malicious activity that is deliberately concealed across multi-step sequences of individually benign operations.

By releasing Project Quarry to the open-source community, Cisco aims to assist organizations in defending AI agent frameworks against evasive threats that bypass single-step detection mechanisms.

### Technical Impact & Root Cause
Traditional security monitoring often fails to detect sophisticated AI agent exploits because each discrete action or command executed by the agent appears harmless when evaluated in isolation. 

The underlying vulnerability stems from the emergent nature of these attacks, where intent and impact only become clear when observing the entire chain of actions. Project Quarry establishes a rule language specifically designed to evaluate these behavioral sequences to surface hidden threat logic.

### Mitigation & IOCs
Organizations utilizing AI agents should consider adopting and integrating Cisco's Project Quarry rule language into their monitoring pipeline to construct detection rules for sequence-based agent attacks.
